# IPTVI

An interface that will receive an M3U8 file and read this

- playlist managment
  - add
  - edit
  - remove

- choose among:
  - movies
  - series

- only one playlist active
  - if a new is added it will inactivate the other
  - user must explicit agree with above

- Player:
  - choose audio
  - choose/add subtitles

- support multi playlist (future)
- support live tv (future)
- home: (future)
  - can filter every movie
  - can filter every series
  - can filter every live
